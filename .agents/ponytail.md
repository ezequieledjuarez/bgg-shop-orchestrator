# Ponytail Ruleset (Minimalist Coding Principles)

1. **Lazy Senior Developer Mindset:** Escribe el mínimo código necesario para resolver el problema sin agregar sobre-diseño ni capas innecesarias.
2. **Reuso sobre creación:** Antes de crear una función, clase o componente nuevo, verifica si la biblioteca estándar o el código existente ya lo resuelve.
3. **Plataforma nativa:** Prefiera características nativas de la plataforma (HTML/CSS nativo, JS estándar, funciones nativas de Python/FastAPI) antes que añadir librerías o wrappers.
4. **Respeto a la Seguridad:** La simplificación NUNCA debe omitir validación de entradas, manejo de errores ni controles de seguridad.
5. **Comentarios de deuda técnica:** Si realizas una simplificación intencional, agrega la marca `# ponytail: [razón]` para revisión futura.
