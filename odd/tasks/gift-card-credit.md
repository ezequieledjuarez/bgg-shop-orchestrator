# Gift Card Credit

## Objective

Let authenticated buyers redeem a single-use gift card and pay for orders using their personal ARS credit, with the authorized Mercado Pago retry safeguards.

## Scope and Constraints

- No expiration, commercial balance limit, credit transfer, card deactivation, transaction history, or split payments in the initial scope.
- Insufficient credit or stock rejects payment without a debit; unused credit remains available.
- Any pending Mercado Pago order belonging to the buyer blocks a new credit checkout, including earlier orders.
- A successful credit checkout blocks retries of all currently rejected Mercado Pago orders for the same buyer, including unrelated historical orders; existing provider preferences are not revoked.
- Late-payment handling, including discovery, reviews, scheduled scans and notifications, is excluded from the remaining work by user request. Existing code and historical evidence remain unchanged; this exclusion does not establish that late-payment risks are resolved.
- This is a non-production practical project. The user waived validation of the Mercado Pago return because no suitable non-local URL is available; the return is not verified.
- The user expects the session to remain in the same tab; cross-tab session sharing is not required by this clarification.
- Cancellation is deferred. A later cancellation must restore the full credit payment once.
- Preserve existing data and uncommitted work; do not commit or perform live provider payments.
- Treat codes as secrets. Require ownership, atomicity, idempotency, concurrency protection, and server-calculated totals.
